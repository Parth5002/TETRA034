# Axiomm Frontend

Enterprise curriculum intelligence dashboard for **TETRA034**.

## Stack
- React 19 + TanStack Start / Router
- Vite 8 + Tailwind CSS v4
- Custom canvas force-graph visualizer
- FastAPI backend on `http://localhost:8000`

## Development

```bash
npm install
npm run dev
```

UI: http://localhost:5173  

Set `VITE_API_BASE_URL` in `.env` if the API is not on port 8000.
